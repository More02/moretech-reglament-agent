# Стоимость эксплуатации

Курс ЦБ РФ на 26.11.2026 - 82,313 ₽/$. Цены модели - официальный провайдер Alibaba Cloud Model Studio,
`qwen3.6-35b-a3b`: $0,375 за 1 млн входных и $2,25 за 1 млн выходных токенов. Токены - замер на прогоне 73 тестовых
вопросов (`reglament eval`) и сценария со службой качества на настоящей модели.

| Шаг | Вызовов на вопрос | Токены вход / выход | ₽ на вопрос |
|---|---|---|---|
| Понимание вопроса (query-understand) | 1 | 1 470 / 85 | 0,061 |
| Ответ с цитатами, по вызову на подразделение (answer-compose) | 1,2 | 2 370 / 205 | 0,133 |
| Разбор письма эксперта (expert-reply-classify), ~10% вопросов | 0,15 | 910 / 75 | 0,006 |
| Разъяснение в базу знаний (clarification-extract) | 0,1 | 1 810 / 210 | 0,009 |
| **Итого** | | | **0,21** |

Без затрат на модель: проверка цитат, чисел и полноты правила - кодом; ответ после кнопки уточнения - без вызова
модели (варианты готовятся заранее); приветствие, вопрос вне базы, посторонняя задача и поиск документа - только
первый шаг; эмбеддинги BGE-M3 - локально на CPU сервера приложения, с дисковым кэшем.

Фактическая стоимость через AI Tunnel (облачный доступ к той же модели в РФ) - около 0,10 ₽ за вопрос: провайдер
возвращает стоимость каждого вызова, она пишется в журнал вызовов и видна в кабинете службы качества.

## Нагрузка заказчика

По данным Softline - 100-300 запросов в месяц на поиск по регламентам; с запасом на рост и на вопросы, которые
сотрудники сейчас не задают, считаем до 200 вопросов в день (~4 400 в месяц): **~920 ₽ в месяц** токенами.

## Свой сервер

- Qwen3.6-35B-A3B в Q4 - ~22 ГБ VRAM: помещается на одну GPU 24-48 ГБ. Профиль `local-llm` поднимает vLLM рядом с
  приложением; адрес модели меняется в `.env`, код не меняется.
- Самый дешёвый подходящий выделенный сервер Рег.облака - 2 × RTX A4000 16 ГБ (32 ГБ) за 70 295 ₽ в месяц со скидкой
  (82 700 ₽ без неё). Аренда фиксированная: ~16 ₽ за вопрос при 4 400 вопросах в месяц; дешевле API от ~335 тыс.
  вопросов в месяц.
- Правильный путь - общий LLM-контур заказчика (у Softline он есть): агент подключается по OpenAI-совместимому API,
  нагрузка на контур - ~2 вызова и ~4-6 тыс. токенов на вопрос.
- Приложение и эмбеддинги - сервер 4 vCPU / 8 ГБ RAM, без GPU.
