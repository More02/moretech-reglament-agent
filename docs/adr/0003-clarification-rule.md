# ADR 0003. Уточнение подразделения по правилу и готовые варианты ответа

**Статус:** принято · **Дата:** 27.11.2026

## Контекст
Заказчик: уточнять, если ответ зависит от контекста; не больше 2-3 итераций; если сотрудник не знает - показать
варианты отдельно с источниками; для комплексного проекта - требования каждой дирекции отдельно, без усреднения.

## Решение
1. Подразделение берётся из вопроса, затем из диалога, затем из профиля сотрудника (имитация SSO).
2. Если оно неизвестно, модель **одним вызовом** готовит ответы для всех подходящих подразделений.
3. Код решает: ответ есть у одного подразделения или ответы одинаковые (одинаковость перепроверяется по числам) -
   отвечаем сразу; ответы разные - уточняем кнопками только из подразделений, где ответ реально есть, плюс
   «Не знаю - показать все» и «Комплексный проект».
4. Варианты сохраняются в состоянии диалога: после нажатия кнопки ответ показывается **мгновенно и без вызова модели**.
5. После `max_clarifications` (паспорт, по умолчанию 2) агент больше не спрашивает, а показывает варианты.
6. Разные правила в разных подразделениях - не противоречие. Противоречие - разные правила для одного случая в
   одном подразделении: агент не выбирает сам и предлагает службу качества.
