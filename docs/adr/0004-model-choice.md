# ADR 0004. Минимальная открытая модель, достаточная по метрикам

**Статус:** принято · **Дата:** 27.11.2026

## Ограничения организаторов
Open weights, лицензия уровня Apache 2.0, веса до 128 ГБ VRAM в квантовании не хуже Q4; облачное API такой модели
допустимо; стоимость - по ценам официального провайдера модели; модели OpenAI не проходят критерий локальной
эксплуатации. Эмбеддинги - тоже открытые.

## Решение
| Роль | Модель | Лицензия | Память (Q4) |
|---|---|---|---|
| Основная LLM | Qwen3.6-35B-A3B, режим без рассуждений | Apache 2.0 | ~22 ГБ, одна карта 24-48 ГБ |
| Запасная LLM | Qwen3.5-122B-A10B | Apache 2.0 | ~70 ГБ |
| Эмбеддинги | BAAI/bge-m3 | MIT | CPU, ~2 ГБ ОЗУ |
| Реранкер (опция) | BAAI/bge-reranker-v2-m3 | Apache 2.0 | CPU/GPU |

Задача агента - извлечение и пересказ по переданным источникам, а не рассуждение «из головы». Здесь MoE-модель с
3B активных параметров даёт скорость и цену при достаточной точности; проверка цитат кодом закрывает её слабые
места. Запасная модель подключается одной настройкой, если тестовый набор покажет недостаточное качество.

Все вызовы модели идут через один шлюз (`adapters/llm_gateway.py`) по OpenAI-совместимому протоколу: облачный
провайдер, локальный vLLM (профиль `local-llm`) или существующий LLM-контур заказчика - смена адреса в настройках.
