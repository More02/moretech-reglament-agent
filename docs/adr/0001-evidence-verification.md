# ADR 0001. Проверка ответа кодом по дословным цитатам вместо второй модели-судьи

**Статус:** принято · **Дата:** 27.11.2026

## Контекст
Заказчик определил недостоверный ответ как ответ, «не соответствующий в точности информации, которая содержится в
регламентах, или дополненный из знаний, не содержащихся в регламенте». Ошибочный ответ для заказчика хуже лишнего
обращения в службу качества. Стандартный приём - вторая модель-судья - удваивает стоимость и время ответа и сам
может ошибаться.

## Решение
Модель обязана вернуть ответ как набор утверждений; у каждого - идентификатор пункта и **дословная цитата** из него.
Код (`libs/evidence`, `skills/answer-compose/verify.py`) проверяет:
1. пункт существует и был среди найденных для этого подразделения;
2. цитата содержится в тексте пункта (допускаются регистр, «ё», кавычки, тире и опечатки при похожести ≥ 92%);
3. все числа утверждения (цифрами и словами: «две недели» = 2) есть в цитате;
4. короткая фраза-ответ не содержит чисел, которых нет в подтверждённых цитатах.

Неподтверждённые утверждения выбрасываются, статусы вариантов пересчитываются. Если не осталось ничего - «ответа
нет», агент предлагает обращение в службу качества. Вторая модель (`answer-verify`) остаётся для строгого режима и
для оффлайн-оценки качества на тестовом наборе.

## Последствия
+ Выдуманный срок, роль или чужой пункт не попадут к сотруднику, даже если модель ошиблась.
+ Ответ стоит один вызов модели, а не два.
+ Сотрудник видит цитату и ссылку на пункт - ответ проверяем.
- Искажение смысла без изменения чисел и цитаты («можно» вместо «нельзя» при верной цитате) кодом не ловится -
  для этого есть `answer-verify` в строгом режиме и метрика в эвалах.
