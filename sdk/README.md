# skill-sdk

Контракт скилла агента. Скилл получает вход (pydantic), контекст (`SkillContext`) и возвращает выход (pydantic) +
замечания проверок кодом (`Issue`). Скилл не ходит в сеть, базу и файловую систему: модель - только через
`ctx.llm`, промпты - из своей папки `prompts/`.

```
вход ──► run(inp, ctx) ──► выход ──► checks(out, inp) ──► замечания
              └─ self.ask(ctx, "<промпт>", content=..., output=...)   модель → JSON → pydantic (extra="forbid")
```

`FakeLLM` - тестовая модель: обработчики по имени промпта, чтобы тесты и эвалы шли без сети.
