# evidence

Проверка ответа модели кодом, без второй модели:

- `find_quote(quote, text)` - дословная цитата есть в тексте пункта (допускаются различия в регистре, «ё», кавычках,
  тире и пробелах, а также мелкие опечатки при похожести ≥ 92%);
- `numbers(text)` - числа из текста, включая записанные словами («две недели» → 2);
- `verify_claim(claim, quote, clause_text)` - цитата найдена и все числа утверждения есть в цитате.
