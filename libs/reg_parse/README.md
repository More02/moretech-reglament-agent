# reg-parse

Разбор регламента в дерево пунктов без модели.

- `read_docx(path)` / `read_html(html)` - абзацы документа в порядке следования (включая таблицы);
- `build_document(...)` - дерево пунктов: номер (`8.4`), путь разделов, текст, родитель, подпункты;
- `find_references(...)` - ссылки на пункты (`п. 8.4`) и на другие документы («регламент подбора субподрядчика»);
- отпечаток (`sha256`) текста каждого пункта - для отслеживания изменений регламента.
