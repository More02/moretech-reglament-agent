# pii-guard

Обезличивание персональных данных (152-ФЗ) перед отправкой текста во внешнюю модель и восстановление в ответе.

- почты, телефоны, СНИЛС, ИНН физлица - регулярными выражениями;
- ФИО - моделью Natasha (MIT, работает локально), если установлен extra `pii`; иначе - шаблон «Фамилия И. О.»;
- одинаковое значение получает один и тот же токен (`[ПЕРСОНА_1]`) в пределах запроса.
